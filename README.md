# Quasi-Riemann Tracker

[![Website](https://img.shields.io/badge/website-gtimg.github.io%2FQuasiRiemannTracker-1d5d74)](https://gtimg.github.io/QuasiRiemannTracker/)
[![Best verified bound](https://img.shields.io/endpoint?url=https%3A%2F%2Fgtimg.github.io%2FQuasiRiemannTracker%2Fbound-badge.json)](https://gtimg.github.io/QuasiRiemannTracker/)

Quasi-Riemann Tracker follows bounds on the real parts of zeros of Dirichlet
L-functions. The [website](https://gtimg.github.io/QuasiRiemannTracker/) shows
how the best bound has improved over time, every submission with its exact
bound, authors, sources and verification status, how submissions build on each
other, and who contributed. Smaller bounds are stronger; the generalized Riemann
hypothesis corresponds to a bound of $1/2$.

Every result on the website is verified. Verification runs through the project’s
GitHub Actions CI. If CI resources run out, maintainers may run the same
verification checks on maintainer infrastructure.

To add a result, see [SUBMITTING.md](SUBMITTING.md). To run the website locally,
host it or operate verification, see [HOSTING.md](HOSTING.md).
