# Reuse and license audit

All source repositories and exact commit hashes are recorded in `dependency-licenses.json`; notices are retained in their original checkouts. The build imports OpenAI and mathlib source under their original names. No source from Liu's repository is fetched or copied.

The selected mathematical source repositories have Apache-2.0 root licenses at their pins: OpenAI/math, mathlib4, PrimeNumberTheoremAnd, and rellich-kondrachov. Mathlib support libraries Batteries, Qq, Aesop, Plausible, ProofWidgets, ImportGraph and LeanSearchClient also have Apache-2.0 root licenses. Source headers and notices are preserved. The selected-module inventory and source headers were rechecked with `scripts/audit_sources.py`; no non-Apache proof-source override was found. The inventory and hashes are in `source-reverification.json`. This provenance check is separate from the kernel axiom audit.

`Cli` is MIT-licensed. It was fetched by Lake because the pinned mathlib configuration depends on ImportGraph's command-line application. It has **zero modules in the selected source proof closure**; no Cli source is copied into or compiled for a mathematical target. It is not admitted as reusable mathematics. Expanding the proof closure to any differently licensed mathematical source requires explicit approval.

OpenAI's compatibility patches for PrimeNumberTheoremAnd and rellich-kondrachov are applied only to the isolated checkouts. Their exact hashes and changed-file lists are in `applied-patches.json`. They are substantive ports, not merely metadata changes, and require independent compilation and axiom inspection. The original licenses and headers remain in place.

Argonaut is inspected but not imported. The complete v0.1.8 archive matches the GitHub release SHA256, and verification-only reconstruction passes for 12055 entries. Its overlay is not applied: its broad reconstruction requests 42 packages, contains substantively changed sources, and uses a different OpenAI pin. Its terminal compilation and Comparator claims have not been reproduced here. It proves a weaker threshold than the requested one in any event.

Compiler: local Lean 4.34.1 release, commit `5045d0056413266e57c625dcd7c365b10e377c52`. Compiler/library notices remain under `toolchains/lean-4.34.1-linux`. Download hashes are recorded independently. No shared configuration, credentials or toolchain has been modified.

A nested-notice search also found MIT notices for ImportGraph's HTML template and Graphology/Sigma browser assets. Those paths contain no selected Lean source modules, are not referenced by the selected ImportGraph Lean sources, and are not reused as formal mathematics or proof evidence. Their notices remain intact in the dependency checkout. The OpenAI `lean/LICENSE` is Apache-2.0. Exact nested-notice hashes/scopes are in `nested-license-notices.json`. PNT's SiegelZeros notice lies outside the selected closure. The final proof imports four Apache-2.0 PNT modules: Fourier, Sobolev, SmoothExistence and Wiener, with the recorded OpenAI compatibility patch.

Original upstream sources remain intact. The other local certificate/geometry modules formalize the supplied manuscript's exact arithmetic, using Mathlib tactics and lemmas by import. The local project is under the retained Apache-2.0 `LICENSE`.

The original sources are unchanged. The final source re-verification found no non-Apache selected owner or conflicting source header; no Cli or browser asset is selected.
