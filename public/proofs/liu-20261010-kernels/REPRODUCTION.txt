No LICENSE or source redistribution grant was found in the pinned Liu tree or
README. The public reproduction package contains our scripts, hashes, reports,
and upstream links. It must not contain the reconstructed Liu source or proof
exports. Running the fetch scripts obtains source directly from upstream.

REPRODUCTION COMMANDS

Python 3.11+, Git, and the declared Lean 4.34.1 compiler are required. Fetch and
restore the exact proof source, with no build or cache assumptions:

  python3 reproduce.py --work /absolute/path/to/fresh-work

To compile using an existing, explicit dependency artifact cache:

  python3 reproduce.py --work /absolute/path/to/fresh-work --build \
    --lean /absolute/path/to/lean-4.34.1/bin/lean \
    --lean-path-file /absolute/path/to/cache-lean-path.txt --workers 8

The cache path file contains colon-separated absolute Lean library roots. The
build-native report records reused artifact hashes. After this build, run the
source/artifact closure inventory with the actual dependency source roots, then
run the separate independent kernel judge. Cached inputs must not be described
as newly compiled. The original tested native invocation was equivalent to:

  python3 build_native.py --package approaches/liu/package \
    --lean compressed/toolchains/lean-4.34.1-linux/bin/lean \
    --lean-path-file compressed/audit/local-lean-path.txt --workers 8
  python3 verify_native.py --work approaches/liu --workers 8
  python3 inventory.py --work approaches/liu --source-root WORKSPACE \
    --dependencies compressed/formalization/.lake/packages

To test fresh source reconstruction against the authenticated recorded build:

  python3 reproduce.py --work /absolute/path/to/another-empty-work \
    --replay-from WORKSPACE/approaches/liu \
    --inventory-sha256 bec4beba107576156a1cbaf2a2deab429c1a95d0e60971ebe404e6d8cc8d0a60 \
    --workers 8

This last command requires access to the recorded local artifacts and source
roots. It is explicitly artifact replay, not a portable binary download or a
new clean build. It authenticates the entire inventory, compiler/build report,
all recorded source and artifact hashes, and the fresh reconstruction before
replaying the original Lean entry. No Liu source is bundled by these scripts.
